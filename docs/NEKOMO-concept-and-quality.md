# 企画相談と製造チャットのつなぎ方

## 製造の実行先

製造はTEST文字プレートを印刷して完了確認するチャット（ローカル保存）で進める予定です。このチャットでは、NEKOMOの世界観、作るもの、要求品質、設計の理由を相談し、製造に渡す条件を整理します。

製造側では、FreeCADによる設計、STLの書き出し、A1 mini向けのスライス、印刷用データの確認、印刷、現物の確認をつなげます。操作方法の希望はCLIまたはMCPを中心とし、GUIは必要な設定変更に限るというものです。

2026年11月9日に製造チャットを参照した時点では、FreeCADとの接続、STL書き出し、スライス、プリンターの状態取得までの確認が報告されています。TEST文字プレートの直接送信は認証で拒否され、原因を調査中でした。この時点の記録では、印刷の完了や製造経路全体の動作確認が済んだとは扱いません。

TEST文字プレートは製造経路を確かめるための試験片です。印刷が完了しても、それだけで玩具としての安全性や品質を確認したことにはなりません。

## 製造へ渡す内容と戻す内容

製造に渡す際は、次の五つを一組にする運用が考えられます。

1. 製品名と改訂番号、対象年齢、用途、想定する遊び方を記した要求仕様。
2. CADと図面、材料候補、可動部や接合部の仕様。
3. FMEAで洗い出した危険と、設計で採った対策。
4. 比較する造形条件と、試作で確かめたい項目。
5. 寸法・外観・強度などの評価方法と合否基準。

製造側からは、使用したCADの改訂、材料と色・ロット、実際の設定、印刷結果、現物写真、測定・試験結果、残った不具合を戻します。企画側では、その結果を受けて形状や条件を更新します。これにより、コンセプトの相談と実際の製作が同じ要求に沿って進む形を目指します。

製造用の作業フォルダーは参照したチャットでは `ローカル保存 です。NEKOMOの企画と品質方針の記録は `ローカル保存 に置きます。製造状況は変わるため、実行時には製造チャットの最新結果を確認します。

# 1 素形材とおもちゃ製造の関係

## 素形材の意味

素形材（そけいざい）とは材料に鋳造・鍛造・プレスなどの加工を施し、製品や部品に近い形にしたものです。鉄やアルミなどの素材から形を作り、必要に応じて切削・研削などで寸法や表面を仕上げます。素形材産業という場合には、こうした成形加工の技術や事業も含めて語られます。

代表例として、鋳造では溶かした金属を型に流し、鍛造では金属に力を加えて変形させます。プレス加工では板材を金型で成形します。ダイカストは鋳造の一種で、溶融金属を金型へ圧入する方法です。粉末冶金では金属粉末を成形し、焼結などによって部品を作ります。

素形材の出来は後工程の加工のしやすさ、完成部品の性能、コスト、納期に関わります。内部欠陥や寸法のばらつきは、仕上げ加工だけでは解決できない場合があります。品質を後工程の検査だけに任せず、形を作る段階から考える理由がここにあります。

## 玩具と3Dプリントへの当てはめ

玩具にも、ミニカーのダイカスト製ボディのように素形材技術を用いる部品があります。一方、プラスチックの部品は通常要望内容や要望内容と呼びます。玩具の成形部品をすべて素形材と呼ぶわけではありません。

3Dプリンターで作る玩具では、要望内容要望内容と呼ぶ方が製法を伝えやすくなります。品質管理では、素形材分野にある要望内容という考え方を取り入れ、確認内容を積層造形に合わせます。

射出成形で確認する金型の抜き勾配やゲート位置を、そのままFDM方式の審査項目にする必要はありません。FDM方式では、積層方向、層間接着、壁厚、充填構造、サポートの配置や除去後の状態が検討対象になります。

# 2 自家使用で目指す品質水準

自家使用でも、設計の根拠と試験結果を残すことには意味があります。破損したときに原因をたどれ、材料や印刷設定を変えたときに再評価する範囲を判断しやすくなるためです。大きな会議を開く必要はなく、一人で行う確認でも、基準と判定を記録すれば設計審査として運用できます。

要望内容という目標は、次のように分けると具体化できます。

| 品質の観点 | 確認する内容 |
| --- | --- |
| 製品安全 | 誤飲、窒息、切り傷、挟み込み、材料由来の危険 |
| 機能と耐久性 | 想定する遊び方で機能し、使用や衝撃で危険な壊れ方をしないか |
| 外観と寸法 | 表面、バリ、重要寸法、はめ合いの基準 |
| 製造の再現性 | 別の日に同じ仕様で作っても要求を満たすか |
| 判断の追跡性 | 図面、材料、設定、試験品、試験結果を対応づけられるか |

外観がきれいでも、内部の接着状態や化学的な安全性は分かりません。高い充填率や大きな外形だけでも安全性は判断できません。品質を詰めるとはそれぞれの要求について確認方法と合否基準を決め、得られた結果に応じて設計を直すことです。

# 3 対象年齢と規格の位置づけ

## 自家使用と販売の区別

日本では2025年12月25日に、乳幼児用玩具に対する子供PSC制度が始まりました。対象は3歳未満向けの玩具で、製造・輸入・販売を行う事業者には、技術基準への適合や表示などの制度上の対応があります。詳細は[日本玩具協会の改正消安法対応の手引き](https://www.toys.or.jp/pdf/2025/ST20250904.pdf)と[消費者庁の制度案内](https://www.caa.go.jp/policies/policy/consumer_safety/child/project_001/mail/20260123)で確認できます。

今回の計画は家庭で作って家庭内で使うものです。販売事業者としての届出やマーク表示の取得を製作の目的には置きません。この整理は自作玩具の安全性を認めるものではありません。販売や配布などに用途が変わる場合は、その時点の条件で制度の適用を確認し直します。

DR0からDR4という審査会議の名称や回数は、ここで提案する管理方法です。法令で定められた会議として扱いません。

## 安全基準を参照する意味

玩具安全の確認では、ST基準やISO 8124シリーズが参照候補になります。ST基準の検査領域には、機械的・物理的特性、可燃性、化学的特性があります。個別項目を評価する要望内容と、STマークを表示するための正式なST検査は区別されています。[日本文化用品安全試験所のST基準案内](https://www.mgsl.or.jp/tests/toys/st/)

添付文にはST2025が候補として挙がっています。採用する基準は版や追補まで特定し、対象年齢、材料、形状、用途に対応する条項を確認してから試験計画に反映します。要望内容要望内容要望内容は、それぞれ異なる状態です。

## 対象年齢を先に決める理由

乳幼児は意図した遊び方に加えて、口に入れる、かじる、投げるといった行動を取る可能性があります。対象年齢によって確認すべき形状や使用状況が変わるため、CADや印刷条件を詰める前に利用者と用途を定めます。

検討資料にある要望内容要望内容は説明に使われた例です。実際の対象年齢と製品形状は確定条件にしません。乳幼児用として検討する場合には、要望内容という設計者の意図だけで、口に入れる可能性を除外しないようにします。

# 4 FDM方式で確認する品質と危険

FDM方式は溶かした樹脂を線状に押し出して層を重ねる方式です。造形物の強度は形状や材料だけでなく、印刷方向や層どうしの接着状態にも左右されます。見た目が同じ部品でも、設定や材料の状態が違えば破損の仕方が変わる可能性があります。

車輪が付いた玩具なら、車輪全体の大きさに加え、車輪の根元や軸受けが割れたときに何が外れるかを考えます。一体造形であっても、破断によって小片が生じる可能性は残ります。窓枠、ミラー、細い柱、装飾の突起なども、通常時の形と破損後の形の両方を評価します。

| 確認対象 | 設計と現物で見る点 |
| --- | --- |
| 積層と強度 | 荷重の向き、層間剥離、薄肉部、突起や結合部の破断 |
| 表面と形状 | 角、鋭利な端、糸引き、バリ、サポート除去跡 |
| 部品と結合 | 車輪・軸・装飾の脱落、接着部、ねじや磁石を使う構造 |
| 材料と使用環境 | フィラメントの品番・色・添加剤、熱、劣化、清掃条件 |
| 造形の安定性 | 空隙、押出し不足、未接着、材料混入、寸法のばらつき |

PLA、PETG、TPUという材料名だけで、乳幼児向けの安全性を判断することはできません。材料を選ぶ際は、メーカー、品番、色、ロット、用途上の注意や提供資料を確認します。塗装、接着剤、異なる材料を追加する場合は、それらも評価対象に含めます。

化学的な安全性は目視や家庭での引張試験では確認できません。必要な試験項目、試料の作り方、対象とする材料や色の範囲は、参照基準と試験所への相談によって具体化します。

# 5 設計審査を五つの段階で運用する

DRはDesign Reviewの略で、設計内容や検証結果を確認し、次の段階へ進めるか判断する活動です。個人製作では、各段階の目的、確認した証拠、残った課題、判定を一つの記録にまとめる方法が使えます。

## DR0 要求仕様の確認

最初に、誰が、どこで、どのように使うかを決めます。対象年齢、遊び方、寸法の制約、可動部の有無、清掃方法、熱や水への接触などが対象です。口に入れる可能性や、落下・踏みつけなどの扱いも検討します。

この段階の成果は要求仕様と評価計画の初版です。要望内容のような表現は、どの部位にどの条件で力を加え、試験後にどの状態なら合格とするかまで具体化していきます。数値の根拠が定まっていない項目は、合格済みとして扱いません。

## DR1 設計の確認

CAD上の形状と材料を確認し、設計FMEAで危険な壊れ方を洗い出します。部品が外れる可能性、割れやすい箇所、角や突起、破断後の小片、清掃しにくい部分などを検討します。

この段階では、検査で見つける方法とともに、危険につながる構造を減らす方法を考えます。一体構造、薄い装飾の削減、結合箇所の削減は候補になりますが、実際に危険を減らせたかは試作品で評価します。図面の改訂とFMEAの対策を対応づけて残します。

## DR2 積層造形工程の確認

設計を安定して造形できるかを確認します。積層方向、壁数、充填率、温度、速度、冷却、サポート、乾燥と保管、後処理を検討します。DFAMはこうした積層造形の特性を踏まえて設計する考え方です。

スライサー画面だけでなく、出力される層や接合部を確認し、試作結果と照らします。設計で必要とした強度が特定の印刷方向に依存する場合は、その方向を管理条件として明記します。

## DR3 試作品の検証

試験品に識別番号を付け、寸法、外観、落下・衝撃、引張・圧縮・ねじり、繰り返し使用、必要な材料試験を実施します。条件、測定値、試験前後の写真、破損位置と判定を残します。

試験条件は対象年齢や適用条項に合わせて決めます。家庭で行う予備評価と、規格に沿った評価は記録上も区別します。破壊試験や劣化試験を行った個体は、子どもに渡す使用品と分けて管理します。

## DR4 使用開始の判定

要求仕様、図面、材料、造形条件、試験結果が同じ仕様を指しているかを確認します。重大な危険への対策と必要な評価が終わり、未解決事項を含めて判断できる状態になってから、使用の可否を決めます。

図面や設定の変更によって、評価済みの試験品と使用品が別仕様になる場合があります。変更による影響を確認し、必要な試験をやり直します。未実施の試験や根拠のない判定を、記録の項目が埋まったという理由で完了にしません。

# 6 FMEAで壊れ方と対策を整理する

## 設計FMEAと工程FMEA

FMEAはFailure Mode and Effects Analysisの略で、不具合の起こり方とその影響を整理し、原因や対策を検討する方法です。設計FMEAであるDFMEAは製品の構造や材料を扱い、工程FMEAであるPFMEAは製造や検査の工程を扱います。

例えば、車輪の根元が細いために割れる問題は設計側の検討対象です。設計で決めた印刷方向を取り違える問題は工程側の検討対象です。層間強度への依存が大きい構造なら、DFMEAで設計上の制約を定め、PFMEAで印刷方向や条件の取り違えを防ぐ管理を考えます。

## 評価点の扱い

Sは影響の重大度、Oは発生のしやすさ、Dは不具合を検出する難しさを表す評価です。RPNは一般にS・O・Dの積で求めます。評価尺度を決めずに点数だけを付けても、項目どうしを適切に比較できません。

添付文にある評価点は一次案として扱い、発生率や強度の実測値にはしません。特にOとDは、試験結果、造形の履歴、検査方法の能力を根拠に見直します。対策後の点数は対策を計画しただけで下げず、効果を確認して更新します。

窒息や重大なけがにつながる項目は、RPNの大小だけで対応を後回しにしません。対策によって発生や検出の評価が改善しても、起きた場合の被害が変わらなければSはそのままです。

## バス型玩具を例にした設計FMEA

次の表は実際のCADと試験計画に結び付けるための検討例です。故障モードと対策案を記載しており、対策の有効性や安全性を確認した結果ではありません。

| 故障モードと影響 | 主な原因の候補 | 対策と確認の方向 |
| --- | --- | --- |
| 車体が割れて破片が生じる | 薄い部分、積層方向、接着不足 | 断面と姿勢の見直し、衝撃後の破片を確認 |
| 車輪や車輪の一部が外れる | 根元の強度不足、結合部の破断 | 接合構造の見直し、引張・ねじり後の脱落を確認 |
| 突起が折れて鋭い面が残る | 細い装飾や角への応力集中 | 装飾の削減と丸み、破損後の形状を確認 |
| 材料由来の危険が残る | 添加剤や塗料などの情報・評価不足 | 材料の特定、用途確認、必要な化学試験 |
| 清掃や使用で劣化する | 清掃条件と材料・構造の不一致 | 清掃条件を決め、処置後の変形・割れを確認 |

PFMEAでは、乾燥不足、誤った設定、別材料の混入、サポート除去時の傷、検査漏れなどを扱います。各項目に対象部位、図面の改訂、対策、確認方法、結果、未完了事項を結び付けると、設計変更の際に再確認する箇所を追えます。

# 7 バス型玩具とA1 miniの検討例

## 仮の製品仕様

検討資料には、外形140 × 65 × 70 mm、PETG、車輪を含む一体構造、可動部なし、室内使用というバスの案があります。接着剤、ねじ、磁石、薄い装飾を避ける案も挙がっています。

これは最初の試作を考えるための候補であり、承認済みの寸法や材料ではありません。一体化によって組立部の脱落箇所を減らせる可能性はありますが、車輪形状の根元が割れないか、車体から小片が生じないかは別途確認します。

## A1 miniの対応と試作条件

NEKOMOではA1 miniを製造に使う予定です。メーカー仕様では造形範囲は180 × 180 × 180 mmで、標準ノズルは0.4 mm、PLA・PETG・TPUなどが適した材料とされています。これは印刷装置としての対応を示すもので、玩具としての安全性を示すものではありません。[Bambu Lab A1 mini公式仕様](https://bambulab.cn/zh-cn/a1-mini/tech-specs)

添付文にある試作条件は比較実験の開始候補として保存します。

| 項目 | 初期候補 | 確定するための確認 |
| --- | --- | --- |
| 材料 | PETGを候補に評価 | 品番と色の特定、材料資料、実際の造形と試験 |
| ノズル径 | 0.4 mm | 形状の再現性と重要部の造形状態 |
| 積層ピッチ | 0.16〜0.20 mm | 外観、層間の状態、強度の比較 |
| 壁数 | 4〜6周 | 実際の壁厚、薄い箇所、破損状態 |
| 充填率 | 25〜40% | 充填構造、外周との接続、要求に対する試験結果 |

これらの数値を組み合わせれば安全になるという意味ではありません。温度や速度は具体的なフィラメントの推奨条件を起点に検証し、比較した条件と結果から採用値を決めます。

柔軟材料の供給方法にも注意が必要です。A1 mini本体のTPU対応とAMS liteでの供給可否は区別します。公式クイックスタートでは、AMS liteでTPUやTPEなどの柔軟材料を印刷しないよう案内しています。[A1 mini Combo公式クイックスタート](https://cdn1.bambulab.com/documentation/Quick%20Start%20Guide%20for%20A1%20mini%20Combo.pdf)

異なる樹脂を組み合わせる場合は、印刷できるかに加え、材料どうしの接合と破損後の脱落を評価します。

# 8 試験計画と合否基準の作り方

試験は確認する要求と対応づけて計画します。各試験について、対象となる図面と造形条件、供試品、方法、合否基準、結果、判定を残します。試験高さ、回数、荷重、保持時間などは、参照規格と対象年齢に応じて定めます。根拠のない共通値を安全基準として流用しません。

| 評価 | 確認する内容と残す記録 |
| --- | --- |
| 外観と寸法 | バリ、欠け、割れ、剥離、異物、重要寸法の測定結果 |
| 落下と衝撃 | 落下方向と床面、条件、試験後の破損箇所と破片 |
| 引張と圧縮とねじり | 負荷の位置・方向・条件、突起や結合部の変化 |
| 繰り返し使用と清掃 | 遊び方や清掃条件に対応する処置、劣化や変形 |
| 材料と化学的特性 | 対象材料・色・表面処理、必要な試験項目と結果 |

小部品の確認は造形直後と負荷試験後の両方で考えます。外れた部品や破片がある場合は、参照基準に沿った小部品評価などで危険を判定します。要望内容という記録だけでは、試験条件が特定できません。

再現性の確認では、同じ設計を複数回造形し、寸法、外観、破損状態などを比べます。必要な試験数は確認したいばらつきと判定の目的に合わせて決めます。少数の試験結果だけで、長期の発生率やすべての個体の安全性まで確定しません。

破損、脱落、未接着などが見つかったら、写真と条件を保存し、FMEAの原因と対策に戻します。設計または工程を修正した後は、その変更が関わる項目を再評価します。

# 9 製作記録と変更管理

記録の中心は、同じ試験結果がどの設計、材料、造形条件に対応するかを分かるようにすることです。CADだけ、写真だけを別々に残すと、後から評価した仕様を再現できなくなります。

| 記録のまとまり | 主な内容 |
| --- | --- |
| 要求と設計 | 対象年齢、用途、要求仕様、CAD、図面、改訂番号、FMEA |
| 材料と装置 | フィラメントのメーカー・品番・色・ロット、乾燥と保管、装置とノズル |
| 造形と後処理 | スライサーのバージョンと設定、印刷用3MF、造形姿勢、印刷日、後処理、個体の識別番号 |
| 検査と評価 | 測定値、試験条件、写真、破片、合否、再試験 |
| 判定と変更 | DRの結果、残る課題、使用可否、変更理由、再評価の範囲 |

材料の品番や色、ノズル、印刷方向、温度、壁数、形状、塗装などを変えた場合は、過去の評価がそのまま使えるかを確認します。外観に関わる変更でも、接合や強度に影響する可能性があります。

使用開始後も、割れ、白化、剥離、変形、鋭くなった箇所、部品の緩みなどを点検し、異常があれば使用を中止します。使用履歴と不具合を次の改訂に反映すると、試作品ごとに品質を改善していけます。

# 10 製作を始める前に決める事項

具体的なCAD設計や試験の準備に進む際は、次の順序で条件を定めます。

1. 実際の対象年齢と遊び方を決め、口に入れる可能性を含む使用状況を整理する。
2. 一体構造か可動部を持つ構造かを決め、材料の品番と色を候補として特定する。
3. 参照する基準の版と適用条項を決め、要求と試験方法を対応づける。
4. CAD上の部位とFMEAを結び付け、比較試作する造形条件を決める。
5. 試作、評価、修正、再評価を行い、記録に基づいて使用の可否を判断する。

最初の成果物は対象年齢と用途を記した要求仕様、設計FMEAの初版、試験計画です。バス型、PETG、外形寸法、印刷設定は検討例として保持し、実際の要求と評価結果に応じて採否を決めます。A1 miniとFreeCADを使う製造経路は、製造チャットの確認結果に合わせて整えます。

# バス型玩具のDFMEA一次案

以下は、バス型玩具で検討した故障モードと仮スコアの例です。S・O・Dは1〜10の仮の評価で、10に近いほど重大、発生しやすい、検出が難しいという想定です。採点基準や発生率の裏付けはなく、NEKOMOの合否基準にはしません。

| IDと故障モード | S・O・D | RPN |
| --- | --- | --- |
| 01 車体が割れる | 10・5・7 | 350 |
| 02 車輪部分が欠ける | 10・6・6 | 360 |
| 03 ミラーなどの突起が折れる | 10・7・5 | 350 |
| 04 屋根が陥没する | 9・5・6 | 270 |
| 05 角が鋭利になる | 7・5・4 | 140 |
| 06 窓や隙間に指が挟まる | 7・4・6 | 168 |
| 07 樹脂から有害物質が溶出する | 9・不明・9 | 算定保留 |
| 08 噛むことで表面が欠ける | 9・5・8 | 360 |
| 09 隙間に汚れが蓄積する | 7・5・7 | 245 |
| 10 熱で変形する | 7・4・6 | 168 |
| 11 重く硬い車体が衝突する | 6・5・3 | 90 |
| 12 底面が反る | 3・6・3 | 54 |

ID02では、突出した車輪を車体側面の浅いレリーフ形状にし、細い接続部をなくす対策案があります。確認方法は設計解析、落下・衝撃試験、試験後の小部品確認です。対策前のS10・O6・D6、RPN360に対し、S10・O2・D3、RPN60が改善目標の例として置かれています。対策後の実測結果や再評価値ではありません。

実際の形状にミラーがなければ、ミラーの故障モードをそのまま残す必要はありません。一体型の車輪でも、根元の形状によっては欠損の検討が必要です。CAD上の部位と照らして、該当しない項目の削除、原因の修正、必要な項目の追加を行います。

化学的安全性は発生度が不明であっても未解決事項として残します。RPNを計算できない項目を、低リスクや対応不要として扱いません。
