# v04設計故障モード影響解析（DFMEA）

## 対象と判定

対象は全長60 mm級の赤白スクールバス設計である。3歳未満向けを目標とし、固定輪、屋根・床を含む一体形状を候補とする。v04 CAD・メッシュ・ファイルのみのスライスを確認した。Native CADとSTEPの再読込では有効な閉じた1ソリッドを確認した。材料の化学資料・ロット、物理的な造形・試験結果は未確認である。本書は設計時点の危険分析で、玩具安全性の認定ではない。

設計候補は要望内容とする。v03の車体・シャーシ・屋根は各1ソリッドの別部品で、`ChassisGuide`と`RoofGuide`の片側すき間は約0.300 mmだった。形状レポートは`roof_retention_validated: false`である。位置決めガイドの存在は保持力の根拠にならない。

## 重大度の区分

重大度は想定される結果の重さだけを示す。発生頻度、検出度、RPNは付けない。

| 区分 | 結果の目安 |
| --- | --- |
| S4 致命的 | 誤飲・窒息、重大な口腔内損傷、指の拘束など、生命に関わる危害につながる可能性。 |
| S3 重大 | 破片、鋭利部、強い挟み込みなど、医療対応を要するけがにつながる可能性。 |
| S2 中程度 | 皮膚のけが、清掃後の劣化、変形や破損による使用不能など。 |
| S1 限定的 | 外観・寸法・組立の不適合など、直接のけがを想定しない品質上の影響。 |

この区分は設計審査内の比較用で、規格の分類や確率評価ではない。結果が複数ある場合は、もっとも重い想定結果を記す。

## 審査状態と未確認リスク

D-01〜D-16の対策は設計候補またはデジタル形状・スライス確認であり、物理的な有効性が実証された意味ではない。要求IDとの照合、CAD・メッシュ・ファイルのみのスライス確認は[試験計画](test-plan.md)と根拠レポートに記録する。表の計画IDは試験計画の確認項目を示し、物理試験を実施した結果や合格を示さない。基準条項番号や試験条件を推測で付けない。

CAD・メッシュ・ファイルのみのスライス確認を記録し、成人向け試作の設計審査を継続できる状態にした。プリンター送信は未許可で、印刷も物理試験もしていない。試験合格を示さず、子どもへの引き渡しは保留する。物理評価、材料評価、適用基準の確認、残留リスクの審査後に別途判断する。

## 設計根拠

v03の既存形状名は[v03ビルダー](../../../../../designs/school-bus-v03-mini/build_bus_v03.py)で確認できる。v03 CAD形状レポート（ローカル保存）は全長60.000 mm、片側すき間約0.300 mm、ガイド壁2.003 mmを記録する。屋根保持は未検証で、子どもの使用も未承認である。再読込レポート（ローカル保存）は3部品を報告しており、v04の構造根拠には使わない。

[v04ビルダー](../../../../../designs/school-bus-v04-dr/build_bus_v04.py)は`PhysicalBus`、四つの内部カラー、`RedModel`、`WhiteModel`を定義する。最終形状レポート（ローカル保存）と最終再読込レポート（ローカル保存）で、保存済みCADとSTEPの一体形状を確認した。最終凸包スクリーニング（ローカル保存）はA-04の内部デジタル基準を通過した。これは物理ゲージ、造形公差、変形、破損を評価しない。スライス検査（ローカル保存）はファイルのみで、プリンター送信を許可しない。代表断面レビュー（ローカル保存）は選択箇所の鉛直断面であり、全体の最小肉厚検査や強度解析ではない。nominal-section-review.json（ローカル保存）も指定断面の計算値に限られる。
