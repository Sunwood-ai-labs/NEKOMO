# v04の設計審査・試験計画

## 判定

この文書はv04のプリント前審査と、別途造形許可を得た後に行う成人向け試作品のスクリーニング試験を定める。試験条件と記録様式の準備は完了した。CAD・STEP・STLのデジタル寸法とA-04は報告書で確認済みである。材料・ロット、現物試験、子どもへの引き渡しは未確認または保留とする。

本書はプリント前審査と、別途許可を得た後に作る成人向け試作品のスクリーニングに使う。プリンターへの送信・造形は未許可で、子どもへの引き渡しは保留する。試験後も、適用法令・化学安全・残留リスクを審査してから使用を判断する。

## 対象と数値の扱い

対象は赤白二色・固定輪・一体形状の全長60 mm級スクールバスである。設計目標は3歳未満向けとする。CAD・STEP・STLの幾何はT-01/T-02のデジタル判定を記録した。現物の安全性と赤白それぞれの材料・色材・ロットは未確認である。

本計画は米国eCFRの玩具試験方法を参照した社内スクリーニングである。試験設備、試料、測定器、実施者が条文どおりであることを確認していない。数値を同じにしても、米国規則、日本の技術基準、ST基準、ISO規格への適合を示さない。日本で製造・輸入・譲渡を行う前に、最新のMETI資料で3歳未満向け玩具の適用範囲を確認する。[出典一覧](sources.md)

数値の区分を混同しない。

- 表中の要望内容は、eCFR条項に記された条件と数値を指す。米国の条文から採った値を明記する。
- 要望内容は、この設計審査で決めた寸法公差、試料数、合否条件を指す。玩具規格の要求値ではない。
- 適用性が判断できない項目はPENDINGとする。必要な測定器や対象年齢別ゲージを推測しない。
- 家庭用の簡易試験手順は定めない。必要な治具・精度・条件を準備できない試験はPENDINGとする。家庭内で参考測定を行った場合も、標準手順の完了や子どもの使用可を示さない。

対象年齢が18か月以下と18か月超36か月以下の双方に及ぶ。eCFR §1500.50は複数年齢帯に及ぶ製品へ最も厳しい要件を適用する。どの試験条件が最も厳しいかを本書で法的に解釈しない。内部スクリーニングでは両年齢帯の該当手順を別試料で実施する。[S-02]

条文はインチ・ポンドを優先する。[S-02] 次のSI値は読みやすさのための換算で、独立した公差や判定値ではない。判定時は表中の原単位を使う。

## 審査の順序

1. v04のCAD、製造メッシュ、3MF、材料割当、サポート配置を照合する。
2. 別途造形許可が出た場合に限り、成人向けエンジニアリング試料を1個作る。
3. その1個でT-00の支持材除去、アクセス、外観、寸法、小部品円筒による初期確認を行う。
4. 支持材を除去できない、または目視で明らかな損傷がある場合は失敗として止め、設計を直す。合格後に限り破壊試験マトリクスへ進む。
5. §1500.51または§1500.52の試験試料は、各試験前に73 ±3 °F、相対湿度20～70 %で4時間以上調整する。調整環境から取り出した後5分以内に試験を始める。温度、湿度、調整時間、取り出し時刻、試験開始時刻を記録する。[S-02]
6. 試験ごとに未試験の試料を割り当て、指定の落下、ねじり・引張り、圧縮、必要時の咬み試験を行う。引張りにはねじりと同じ試料を使う。
7. 各試験の前後で写真と損傷を記録し、全破片を小部品円筒で確認する。
8. 材料・清掃資料と開口部の評価を閉じ、未解決項目がないことを別途審査する。

§1500.50(b)(3)は引張試験を除く各試験を未試験試料に適用し、引張試験はねじり試験と同じ試料に適用する。内部計画もこの割当を守る。[S-02]

## 試料と記録

各破壊試験セルにつきn=3とする。これは工程ばらつきを見るための内部基準で、eCFRに定められた試料数ではない。各試料は別の造形ロットまたは別の造形ジョブから採り、赤白両方の材料・色材と予定工程を含める。T-10を行う場合も、年齢帯ごとに別の3試料を使う。

試料IDは `V04-B###-T##-R#` とする。`B###`は造形ロット、`T##`は試験ID、`R#`は1から3の反復番号である。試験前に実際のIDを割り当てる。別の破壊試験に使った試料を再利用しない。ねじり後に行う引張りだけは同じ試料を使う。小部品円筒による初期・試験後確認は各試料に併記する。

記録には次を残す。

- CAD、メッシュ、3MFの改訂番号とSHA-256、造形日時、担当者、プリンター識別子、スライサーと設定の改訂番号。
- 赤白それぞれの材料名、製造元、製品番号、色材、ロット、供給者資料の版。
- 造形方向、ノズル径、積層高さ、壁数、充填、温度、速度、支持材と除去手順。
- §1500.51／§1500.52の試験では、試験前の温度73 ±3 °F、相対湿度20～70 %、4時間以上の調整、試験開始まで5分以内の記録。
- 試料ID、質量、外形寸法、測定器IDと校正状態、試験治具と校正状態。
- 試験条件の実測値、各負荷・落下後の所見、破片の数と寸法、写真、判定者、実施日。

資料が欠ける試料、異なる材料・色材・造形設定を混ぜた試料、識別できない試料は試験に使わず、PENDINGとする。

### 対象外にする試験

§1500.51(d)の屈曲試験は、形状保持に用いる金属ワイヤー等の金属部材を含む場合に適用性を再確認する。内部設計条件R-08は追加ハードウェアを使わないが、v04の材料・部品表が未確認なので、現状は非該当とせずPENDINGとする。金属部材がないことをCAD・部品表・材料記録で確認した後に限り、適用外として記録できる。

## 合否と再試験

内部スクリーニングは、同じ試験セルのn=3試料がすべて規定条件を満たし、事前・各負荷後・試験後の記録が揃った場合だけ合格とする。ひとつでも内部不合格条件が出れば、そのセルを不合格とし、子ども使用を承認しない。測定器の精度、治具、試験条件、試料識別の記録が欠けた場合は合格にせずPENDINGとする。

設計を直した後は、変更した材料・色境界・形状・造形設定に影響する試験を、未試験の新しい試料で繰り返す。結果の平均で不具合を相殺しない。再試験の範囲と残留リスクは別の設計審査で承認する。

本計画だけで適合性を判断しない。METIは3歳未満向け玩具の技術基準、自主検査・記録、年齢表示と保護者の監督表示を案内し、ST基準との関係も説明している。該当性、必要な試験、表示、材料の化学評価は最新資料と試験機関で確認する。[S-01]
