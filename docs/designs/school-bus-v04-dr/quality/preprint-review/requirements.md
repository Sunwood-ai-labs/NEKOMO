# v04要求仕様

## 状態

本書はDR0の要求とDR1の設計判断を記録する。v04のCAD・STL、独立再読込、STEP、メッシュ、スライス後3MFのファイル検査を実施した。最終再読込レポート（ローカル保存）ではNative CADとSTEPが有効・閉鎖・各1ソリッド、外部文書参照0と記録されている。再メッシュ化寸法は60.00000024 × 33.99999928 × 35.56793406 mmでA-03のCAD寸法範囲内である。最終STLの凸包内接球直径は33.399924 mmで、内部A-04の33.0 mmスクリーニングを通過した。赤白領域の交差、全体からの欠落、全体外へのはみ出しは集合差評価で0と記録された。raw volume-sum差2.7486 mm³はB-spline体積積分の診断値であり、形状の集合差による合否判定には使わない。ファイル検査したスライスではモデル材と支持材の割当が分かれていた。これらはデジタル設計確認であり、造形後の物理寸法、支持除去、材料安全性、強度、破損後の小部品、子どもの使用を示さない。物理評価と材料・子ども向け試験は未実施で、全体の適合判定は保留する。

## 利用者が指定した要求

| ID | 要求 | 確認方法 |
| --- | --- | --- |
| R-01 | バスは赤と白で表す。 | CADの赤白領域と材料割当を照合する。色の配置は本要求では指定しない。 |
| R-02 | バスの全長はおよそ60 mmとする。 | 最終CADの全長を記録する。許容差は内部基準A-01に分ける。 |
| R-03 | 参考画像に沿うバスの外観を保つ。 | CADの正面、側面、上面、組立表示を参照画像と照合する。 |
| R-04 | 車輪は固定し、回転させない。 | CADで車輪と車体・床の連続性を確認する。可動軸を設けない。 |
| R-05 | 3歳未満向けを設計目標とする。 | 対象年齢の目標として記録する。玩具としての適合や使用可を意味しない。 |
| R-06 | プリンターにデータを送らず、印刷開始前で止める。 | 送信・加熱・造形を行わない。ファイル検査レポートでは`dispatch_authorized: false`。成果物は設計・データ審査段階に留める。 |

## 内部の設計要求とリスク管理上の制約

| ID | 要求 | 区分と確認方法 |
| --- | --- | --- |
| R-07 | 屋根・車体・床を一体の物理形状にし、意図して取り外せる部品を設けない。色は同一形状内の赤白領域で表す。 | 内部のリスク対策。`PhysicalBus`の最終CADが有効な閉じた1ソリッドであること、`RedModel`と`WhiteModel`の領域が物理形状を過不足なく分けることを確認する。geometry-reportと独立再読込レポートでは物理形状が有効・閉鎖・1ソリッドと記録された。赤白セットは閉鎖し、交差・欠落・過剰が0。raw volume-sum差2.7486 mm³はB-spline体積積分の診断値として残し、集合差による合否判定とは区別する。これはCAD形状の確認で、接合強度、層間強度、破損後の小部品を証明しない。 |
| R-08 | 選択した一体設計にねじ、磁石、車軸などの追加ハードウェアや接着剤を使わない。 | 内部の設計選択。CAD部品と組立手順で確認する。利用者が明示した禁止事項ではない。 |
| R-09 | モデル形状にサポート材を含めない。 | 内部の品質制約。CAD・モデル用メッシュと材料割当を確認する。ファイル検査レポートではPLA-Sが支持界面とプライムタワーのみに割り当てられ、モデル経路は0。支持材除去後の残材・表面状態は未確認。 |
| R-10 | 子どもへの引き渡しを保留する。 | 内部のリスク管理上の保留。現物、材料、適用基準、残留リスクを評価するまで使用可と記録しない。 |

## 内部の設計スクリーニング基準

| ID | 基準 | 区分と限界 |
| --- | --- | --- |
| A-01 | CAD全長60.0 ± 0.5 mm。 | 約60 mmという利用者要求を確認するための内部許容差。現物寸法や造形公差を保証しない。 |
| A-02 | 荷重を受ける壁・柱・根元の公称肉厚は2.0 mm以上を目標にする。 | 内部の設計基準で、安全規格の値でも強度の証明でもない。nominal-section-review.json（ローカル保存）はv03由来の指定断面を幅だけ拡張した計算で、側壁2.400 mm、後壁2.246 mm、窓柱3.744 mm、側窓上桟2.995 mm、床4.493 mm、車輪厚3.200 mm、座席背3.370 mmを記録する。この記録は全体の最小肉厚検査ではない。v03車体だけで測ると前窓上枠は約1.872 mmだが、屋根融合後の独立した梁厚ではない。屋根と連結カラーを含む最終形状をZ方向に通して断面を調べる。ビルダーのカラー座標からはZ方向2.059 mm、X方向2.527 mmとなるが、コードの近くにある1.87 mmというコメントとは一致しない。最終形状の局所厚さと荷重経路を確認し、全体合格を主張しない。 |
| A-03 | CAD寸法の設計目標を長さ60.0 mm、幅34.0 ± 0.5 mm、高さ35.568 ± 0.5 mmとする。 | 幅と高さ、およびその許容差は利用者が固定した寸法ではない。v03 STLの幅31.824 mmでは、凸包の最大内接球直径が31.373 mmで内部33 mmスクリーンを満たさなかった。幅34.0 mm候補では33.402 mmとなった。最終v04全体STLは59.99975 × 34.000 × 35.568 mm。最終再読込レポート（ローカル保存）のNative CAD・STEP再メッシュ化寸法は60.00000024 × 33.99999928 × 35.56793406 mmで、いずれもこのCAD寸法範囲内。BRepのカーネル境界値は診断用に残し、主寸法には使わない。根拠は幅候補スクリーニング（ローカル保存）、最終形状レポート（ローカル保存）、メッシュレポート（ローカル保存）。これはCAD・メッシュ寸法で、造形後の寸法ではない。 |
| A-04 | 最大内接球の直径が凸包内で33.0 mm以上となる候補を採る。 | STL頂点の凸包半空間に対する線形計画による内部スクリーニング。最終STLハッシュを照合して再計算した内接球直径は33.399924 mmで、A-03寸法範囲とともに内部設計スクリーニングを通過した。根拠は最終Hullスクリーニング（ローカル保存）。玩具規格の値ではなく、物理ゲージ、造形公差、変形、破損、全形状・全高のゲージ試験を代替しない。合格を実ゲージ適合と表現しない。 |
| A-05 | 赤白の色領域は物理形状の内部領域に分ける。 | 配色配置の具体化は設計選択。色境界の接着、層間強度、口腔接触時の安全性はCADから判断できない。 |
| A-06 | 支持材へアクセスでき、除去後に見えない残材を残しにくい姿勢と形状を選ぶ。 | 内部設計上の目標。スライス経路と現物で確認する。サポート不要とは仮定しない。 |

## 設計候補の比較

| 候補 | 利点 | 主な不利益・未解決リスク | 判定 |
| --- | --- | --- | --- |
| A. 屋根・車体・床を別体にし、追加ハードウェアなしの保持形状で固定する | 部品ごとに色・姿勢を分けやすく、内部にアクセスしやすい。 | 保持形状が抜けたり壊れたりすれば別体部品になる。スナップ根元に組立・反復荷重が集中し、亀裂や破片を生む可能性がある。v03の`ChassisGuide`と`RoofGuide`は位置決め用で、保持力を検証していない。 | 今回は選ばない。 |
| B. 屋根・車体・床を一体形状にし、赤白の材料領域を残す | 意図した屋根・床の脱落界面をなくす。追加ハードウェアや接着剤を要しない。 | 色境界・層間、車輪・窓柱の破損、鋭利な破片、窓の指挟み、支持材の残留、材料・清掃・熱のリスクは残る。一体CAD形状だけで破損後の小部品を否定できない。 | 内部設計案として選ぶ。CAD・メッシュ・スライスのデジタル確認を記録し、印刷と子どもの使用は保留する。 |

## 審査状態

DR0では利用者の指定と内部基準を分けて記録した。DR1では候補Bを選び、設計候補Aとの危険差を[dfmea.md](dfmea.md)に記録した。CAD・STEP再読込寸法、単一ソリッド、赤白領域の集合差、全体STLの凸包スクリーニング、ファイルのみのスライスと材料割当を確認した。これらはデジタル設計確認であり、規格適合、物理ゲージ合格、強度、支持除去後の表面、材料安全性、子どもの使用を示さない。物理試験は[試験計画](test-plan.md)でPENDINGのままである。

プリンター送信は許可されていない。子どもへの引き渡しは保留する。
