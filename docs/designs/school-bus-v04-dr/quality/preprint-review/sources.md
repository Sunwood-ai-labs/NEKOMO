# 試験計画の出典

## 出典の使い方

2026-11-09に一次資料を確認した。eCFR各ページは閲覧時点で2026-11-05現在のTitle 16を表示していた。試験を実施する時点でも最新条文を確認する。

本計画はeCFRの公開手順を社内スクリーニングへ転用する。測定器、試料、実施方法の適合性を検証していないため、条文と同じ数値を使っても規則適合を主張しない。日本での3歳未満向け玩具の法的扱いはMETIの現行資料と専門機関で判断する。ISO・STの非公開本文を参照したり、未確認の条項番号や要求値を補ったりしていない。
