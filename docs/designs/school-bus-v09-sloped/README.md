# 傾斜ボンネットの支持材なし検証 v09

ユーザーの提案に沿って、ボンネット全体を前下がりの滑らかな曲面に変更した。屋根を下にした印刷で、車体から一層ずつ伸びる形にした。v08の角を丸めるだけの案を採用せず、空中から始まる棚状のボンネットをなくした。元版は`before/`にCADと設計スクリプトを保存した。

## 変更

全長42 × 幅21 × 高さ24 mm、床なし、空洞、貫通窓、固定輪を維持。曲面のXZ制御点は(0,5.2)、(3,8)、(5.6,11.4)、(9,14.8) mm。前窓の下端を14.2から16 mmへ上げ、曲面の後端を支える車体部分を残した。ボンネット殻の内面は上面曲線からZ方向に2.4 mm下げた。白屋根、赤い車体とタイヤの配色。

## 検証

1. 保存したFCStdを開き直し、有効で閉じた1ソリッドと床の開放を確認した。
2. FreeCADの実形状をy=-5、0、5 mmで切り、印刷高さ9.7〜22.1 mmを0.2 mm刻みで比較した。前端が一層で前へ伸びる最大量は旧版5.285565 mm、新版0.210875 mm。曲面の理論上限0.214286 mm以内だった。`evidence/freecad-sections.json`に各層の値がある。
3. 保存済みG-codeのボンネット中央を検査した。配置後座標x69〜75.8、y85〜95、z10.2〜19.0 mmを対象に、押出経路を0.15 mm以下の間隔で調べた。円弧G2/G3も0.08 mm程度以下で分割し、G90/G91、M82/M83、G92を処理した。各経路と前層の押出線幅領域の重なりを調べた結果、新版25,497点で非重複は0点。最も重なりの少ない箇所でも約0.204 mmの重なりがあった。旧版は18,030点中858点で0.03 mmを超える隙間があり、最大約4.833 mm離れていた。`verify_toolpaths.py`で再実行できる。
4. A1 mini・0.4 mm・PLA Basic・0.20 mm層・3壁・15%充填・支持材OFF・プライムタワーありでスライスした。終了コード0、警告なし、色替え1回、総予測時間1770.93秒（約29分31秒）、総材料約5.73 g。最終3MFをファイル単位で再検査した。

判定は要望内容。G-code検査はボンネット中央に限定し、窓やタイヤを含む全体の実造形合格を意味しない。断面と押出幅の重なりは幾何学上の値で、冷却・接着・押出量・表面の滑らかさは実物で未確認。冷却・取り外し時間は予測に含まない。印刷機への送信や実印刷はしていない。
