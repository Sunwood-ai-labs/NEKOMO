# v04中央窓の支え除去クーポン

## 目的

v04の`PhysicalBus`から、グローバルX=26.5〜41.5 mmの範囲を切り出しました。中央窓、屋根、座席、床の形状を含み、元形状のY方向34 mm全幅を保っています。色分けを外した単色のクーポンです。

## クーポン用の加工

- 切断端から支えを取り出せて評価が簡単にならないよう、窓の端で止まる端蓋を付けました。前側はX=26.5〜28.45 mm、後側はX=39.68〜41.5 mmです。どちらも窓のX範囲28.45〜39.68 mmには重なりません。
- 端蓋の断面はY=-0.5〜29.3 mm、Z=8.2〜31.075 mmです。端蓋はクーポン専用で、支えの枝分かれ方に影響する場合があります。
- 底面を平らにするため、Z=3.744 mmより下の部分的な後輪弧をクーポンから除きました。この加工もクーポン専用です。

## 形状確認

元形状の実寸は密メッシュで測り、60.000×34.000×35.568 mmでした。クーポンの実寸範囲はX=26.5〜41.5 mm、Y=-2.586〜31.414 mm、Z=3.744〜35.568 mmです。測定条件は線形偏差0.005 mm、角度偏差0.06 radです。

元の`PhysicalBus`と再読込したFCStd形状は、それぞれ有効で閉じた1ソリッドでした。STEPを書き出して読み直した形状も有効な1ソリッドです。STLは98,758面で、FCStdとSTEPのメッシュ範囲に一致しました。元FCStdのSHA-256と実測値は`coupon-geometry.json`に記録しています。

## ファイル

- `v04-middle-window-support-removal-coupon.FCStd`：単一の`Part::Feature`として保存した形状
- `v04-middle-window-support-removal-coupon.step`：STEP出力
- `v04-middle-window-support-removal-coupon.stl`：単色STL出力
- `build_coupon.py`と`coupon-spec.json`：別のソース形状にも使える切り出し・端蓋生成スクリプトと入力値
- `coupon-geometry.json`：ソースハッシュ、実寸、ソリッド検査、出力再読込の記録

この確認で分かるのはCAD形状と出力ファイルの整合性です。まだ印刷していないため、実物から支えを外せるかは未確認です。このクーポンは車体全体の造形や、色材どうしの接着、子ども向けの安全性も確認しません。
