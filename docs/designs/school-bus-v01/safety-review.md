# NEKOMO スクールバス型玩具の設計審査・現物試験計画

対象: 家庭内の自家使用を想定。3歳未満向けを設計目標とする。

## 1. 審査判断

DR1（設計方針） 試作準備を条件付きで継続する。一体造形、固定車輪、別体部品を設けない方針を採用案として確認した。これはCAD・スライス確認を続ける判断であり、印刷送信、造形開始、対象年齢への適合、子どもの使用を承認するものではない。

DR2（CAD・スライス） 試作データの全体検査を確認した。FreeCADで閉じた有効な1ソリッド、STLで境界・非多様体エッジなし、全体の接続を確認した。2色版と単色版のスライスおよび印刷ファイル検査は通過した。根拠はevidenceのgeometry-report.json、mesh-report.json、sliceとinspectionの各JSONに保存している。下記DFMEAの個別項目や現物の安全性については、全体検査の通過だけで完了にはしない。

DR3（試作品） 現物試験は未実施。印刷試作品はまだなく、保留とする。  
DR4（子どもの使用） 判定未実施。DR2・DR3の完了と残留リスクの審査まで保留とする。

## 2. 対象設計と判断の前提

採用案は車体、屋根、座席、固定車輪、前後灯、ハブを一体で造形する構成である。車輪は回転させず、ねじ、磁石、車軸、接着剤、差し込み式部品も設けない。2色は同じモデル内の材料領域で同時造形する案とし、別取付部品を増やさない。

最終CADの外形は長さ154.5 mm、幅72 mm、高さ86 mm。車体長150 mmに対して、ライトと屋根の張り出しを含む。側壁5 mm、窓柱10 mm、屋根裏45度、中央の橋渡し20 mmは、造形検討用の設計値である。安全基準の許容値や合否値ではない。

試作材料にはBambu PLA Basicを選定している。現時点でA3に赤色PLA Basicが1本装填されていることだけを確認済みで、希望する黄色とココア色の実フィラメントは未確認である。色材、品番、ロット、材料領域とスライサーの対応を確認するまで、希望配色での材料評価や色境界の評価はできない。

本書は日本国内での家庭内自家使用を想定する。3歳未満向けを設計目標とするため、実際の使用形態に適用される規格・条項を特定してから、評価範囲と判定条件を決める。法令上の適用範囲や表示要件は本書では判定しない。

## 3. 定性的DFMEA

以下は想定する故障と危険、設計上の対策、CADで確認する内容、現物で行う検証をまとめたもの。S/O/Dの点数やRPNは付けない。要望内容は証拠の有無を表し、安全性の評価点ではない。

1. 屋根・窓柱の破損。 故障・危険: 屋根や柱が割れ、鋭い縁や小片が生じる。設計対策: 屋根を車体に一体化し、窓柱と丸みを設ける。CAD確認: 実際の断面、接続、丸み、屋根裏と窓上の造形経路を確認する。現物検証: 該当する機械的強度試験後に破損、小片、先端・縁辺を確認する。状態: CADの全体形状は確認済み。局所の断面と破損後の状態は現物未評価。
2. 固定車輪・ハブ・灯・座席背もたれの欠損。 故障・危険: 根元が割れて部品や破片が外れ、誤飲や口・皮膚のけがにつながる。設計対策: これらを車体に一体化し、独立部品を作らない。CAD確認: 連続形状か、根元に局所的な薄肉や分離ソリッドがないかを確認する。現物検証: 適用条項に基づく引張り、ねじり、曲げ、落下等の後、小片や鋭利部の有無を確認する。状態: CADの一体性は確認済み。部位の破損・脱落・剥離は現物未評価。
3. 窓や隙間への指の挟み込み。 故障・危険: 開口部に指が入り、抜けにくくなるか、縁で皮膚を傷つける。設計対策: 可動部を設けず、窓の角を丸める。CAD確認: 窓、屋根下、座席周辺など、触れられる開口と隙間を抽出する。現物検証: 年齢区分に適用されるゲージや開口部試験で確認し、鋭利な縁も評価する。状態: 適用基準・判定条件未特定、開口部の規格照合と現物評価は未完了。
4. かじりによる欠け。 故障・危険: 表面や突起が欠け、小片の誤飲や口のけがを招く。設計対策: 小さな別体装飾や接着部品を設けず、露出する形状を一体化する。CAD確認: 薄い縁、細い突起、局所的な薄肉を洗い出す。現物検証: 対象玩具に適用される通常使用・合理的に予見可能な誤使用の試験条件を特定し、破片と先端・縁辺を調べる。状態: 全体形状は確認済み。局所の肉厚の規格照合と破損抵抗は未評価。
5. 異色領域の剥離。 故障・危険: 色境界または層間が剥がれ、異色片が外れる。設計対策: 2色を同一モデル内の材料領域として配置する。別取付部品や接着に依存しない。CAD確認: 材料領域の接触、重なり・隙間、境界部の連続性を確認し、スライスで材料切替と経路を確認する。現物検証: 実際に使う両色の材料で造形し、該当する強度試験後に境界を観察する。状態: 黄・茶フィラメント未確認。CADの一体性は確認済み。部位の破損・脱落・剥離は現物未評価。
6. 材料・色材への口腔接触。 故障・危険: 材料成分や色材が接触・溶出し、化学的な懸念が残る。設計対策: 材料をBambu PLA Basicに限定する案とするが、材料選定だけで安全性を判断しない。CAD確認: 化学的安全性はCADから確認できない。現物検証: 実使用する各色の品番・ロット・資料を特定し、適用条項に従う試験の要否と条件を決める。状態: 赤色のみ装填確認。材料資料・化学試験は未確認・未実施。
7. 汚れ残りと清掃による劣化。 故障・危険: 客室内や積層面に唾液・食品・汚れが残り、清掃後に割れや剥離が生じる。設計対策: 清掃具が届かない閉じた空洞や不要な細溝を避ける。CAD確認: 客室内、座席周辺、下面の清掃経路と支持材の残留箇所を確認する。現物検証: 想定する清掃方法で汚れ残りと表面損傷を確認し、材料に合う洗剤・温度・手順を決める。状態: 清掃方法と耐久評価は未決・未実施。
8. 熱による変形・燃焼。 故障・危険: 熱で形状や強度が変わる、または燃焼によりやけどにつながる。設計対策: 熱源を組み込まない。PLAであることだけを耐熱性や難燃性の根拠にしない。CAD確認: CADでは熱特性や燃焼性を判定できない。現物検証: 保管・清掃時の温度条件と、玩具に適用される可燃性試験の要否を分類後に決める。状態: 熱・可燃性評価は未実施。

## 4. 試験の進め方と審査段階

1. DR2の個別項目を確認する。 全体形状と印刷ファイルの検査に加え、局所の最小肉厚、窓柱、屋根・座席・車輪・灯・ハブの接続、一体ソリッドとメッシュの状態、材料領域の重複・欠落を記録する。スライスでは造形範囲、向き、屋根裏45度と20 mm橋渡し、窓上の経路、支持材、警告、予測時間・材料量を記録する。各値は実ファイルから採り、未確認事項を推定で補わない。
2. 試験条件を決める。 対象年齢・製品区分・適用基準を確認し、DFMEA項目ごとの該当条項と試験方法を特定する。荷重、トルク、回数、落下条件、温度、ゲージ、合否値は、その条項を確認した後に記録する。本計画では具体値を設定しない。
3. 管理した試作品でDR3を行う。 使用したプリンター、ノズル、材料の色・品番・ロット、スライサープロファイル、造形方向を記録する。試験前後の写真と観察結果を残し、破断、剥離、脱落片、小片、鋭利な縁・先端、窓の挟み込み、清掃後の損傷を確認する。基準に適合する測定器具や外部検査が必要な項目は、自己流の荷重・回数で代用しない。試作品が造形できても、安全性の合格とはしない。
4. DR4の判定を保留する。 法令・規格上の要求、材料評価、機械的試験、開口部、清掃・劣化の結果をそろえて設計審査を行う。適用基準に照らした未解決の危険が残る場合は、対象年齢向けの使用を承認しない。材料、色、形状、造形条件を変えた場合は、影響する確認項目を見直す。

玩具の物理・機械、可燃性、化学的安全性の検査項目は[日本文化用品安全試験所の玩具安全検査案内](https://www.mgsl.or.jp/tests/toys/)を参照する。消費者庁の子ども安全メールは[指定された参照ページ](https://www.caa.go.jp/policies/policy/consumer_safety/child/project_001/mail/20210225/)を参照する。これらは試験・適用条項を選ぶための参照資料であり、本品の適合証明ではない。
