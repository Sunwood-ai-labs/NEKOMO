参照画像の黄色と茶色の丸みあるバスを、車体・シャーシ・屋根の3部品で組むCAD試作です。3歳未満向けを目標にしていますが、安全評価は未実施です。プリンターへの送信と印刷はしていません。

v02を現在の設計として扱い、v01の記録も保持しています。車体内で保持する回転車軸の案は将来候補にとどめ、この版は固定輪です。

## 形状と配色

CAD上の組立外形は約160.26 × 85 × 95.00 mmです。車輪は直径34 mmで、シャーシと一体の固定輪です。回転軸はありません。

| 部品 | 形状と設計色 |
| --- | --- |
| 車体 | 金色 `#E6B34A`。茶色の帯とランプ周り、アイボリー `#F4E2BB` のライトを含みます。 |
| シャーシ | 床、座席、固定輪を一体化した茶色 `#76503B` の部品です。ハブはアイボリーです。 |
| 屋根 | 茶色 `#76503B` の独立部品です。 |

ライトとハブは小さな別部品ではなく、各部品内の色領域です。色境界の接着強度や剥離は実物で確認していません。

材料合計にはモデル材、支持材、パージの推定値が含まれます。プロファイルの `main_used_g` にはPLAの支持材も含まれるため、モデルだけの量として扱いません。これらはスライサー予測で、実際の時間と使用量ではありません。スライス結果は3部品とも成功し、警告欄は空です。最終3MFの検査記録は下記の証拠ファイルにあります。

プロファイルはモデル色間のフラッシュ量を350 mm³、モデルから支持材への切替を500 mm³、支持材からモデルへの切替を800 mm³と仮定しています。この値は未検証です。フラッシュ材をモデルや支持材へ混ぜる設定は無効です。

比較用のスライスでは、シャーシを横向きにすると直立時より約1時間25分短く、約16.42 g少なく、色替えが68回減りました。車体を逆さにした案は、直立時より約32分49秒長く、約14.27 g多く、色替えが2回増えました。比較記録（ローカル保存）の値はいずれもスライサー予測です。

## 配色と安全確認の状態

設計色は金色・茶色・アイボリーですが、実機のフィラメント色は確認できていません。現在の装填表示はA1白PLA、A2白PLA-S、A3赤PLA、A4空です。印刷前にスライサーの色と材料の割当を確認してください。

形状レポートでは、各部品が有効な1ソリッドで、部品間のCAD干渉は0 mm³です。屋根には高さ5 mm、肉厚3 mmの位置決めスカートがあります。シャーシ側のガイドは高さ4.5 mm、肉厚3 mmです。両方とも片側0.35 mmの設計すき間を持ちます。屋根やシャーシの保持力は未検証です。

3歳未満向けは目標で、子どもの使用承認はありません。破損、小片、挟み込み、色境界の接着、材料、清掃と劣化を実物で評価する必要があります。家庭での試験だけでは規格適合を認定できません。
