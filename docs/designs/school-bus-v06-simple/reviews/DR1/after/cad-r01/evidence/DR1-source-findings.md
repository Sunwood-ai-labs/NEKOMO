# DR1 初回ソース確認での指摘

初回CAD実行前のソースをsource-draft-r00へ保存した。

1. 失敗時のstaging削除は、失敗証拠を保持する方針に合わない。失敗を削除せず記録して残す。
2. 出力はr00固定のため、修正後に別版を生成できるようrevisionを明示し、同版の上書きは禁止する。
3. Bambu process profileに説明用の独自項目が混在していた。説明はgeometry reportへ移し、process値はスライサーの文字列形式に揃える。
4. closedという判定名にソリッド数だけを使っていた。isClosed()の実測値を別に記録する。
5. 中間フィーチャーの表示を明示的に隠し、最終Tipだけ表示する。

担当へ修正を依頼。CADの形状が有効かは、まだ実行前のため未確認。
