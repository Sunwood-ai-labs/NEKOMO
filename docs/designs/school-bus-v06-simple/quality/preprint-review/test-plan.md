# v06-simple 試験計画

## 状態と試験の範囲

版: 0.1.0  
状態: 計画のみ。CAD・スライス・現物試験は未実施  
日付: 2026-11-09

本計画は成人向け造形評価試作の形状、工程、時間目標を確認する。玩具安全性、子ども使用、規格適合を判定しない。安全上の数値基準、寸法許容差、荷重、反復回数は設定しない。

## 確認項目

| ID | 確認対象 | 方法と判定 | 現状 |
| --- | --- | --- | --- |
| T-01 | CAD・メッシュの外形寸法 | 再読込したCADと出力メッシュの境界箱を測り、40 × 20 × 22 mmの目標との差を記録する。許容差は未指定なので、測定値だけで合否を作らない。 | CAD未生成 |
| T-02 | 一体形状と外観仕様 | CADとメッシュが閉じた1ソリッドであること、車内・座席・組立部品がないこと、丸角・浅い窓Pocket・浅い円形タイヤPocketがあることを確認する。CAD断面で薄肉箇所を記録する。 | CAD未生成 |
| T-03 | CADとメッシュの版・形状の一致 | CAD、メッシュ、3MFを再読込し、改訂番号・SHA-256・境界箱を記録する。古い版や尺度違いがあればスライスへ進めない。 | 出力未生成 |
| T-04 | 単色・支持なしのスライス | 赤PLA Basicを本体材とする初期候補について、材料割当、平底の配置、支持設定、支持経路、警告、各層の形状を確認する。支持経路が生じたら要求未達としてCADまたは姿勢を見直す。 | スライス未実施 |
| T-05 | 初期造形条件と印刷時間予測 | 0.4 mmノズル、0.20 mm積層、3 walls、15% gyroidを初期候補として記録し、実際のスライサー設定と照合する。実機ノズルは未測定。予測印刷時間が45分以内か記録する。 | スライス未実施 |
| T-06 | 試作品の造形開始判定 | CADと3MFの版、材料と色、実機ノズル、スライス設定、支持なし、時間予測を照合する。現在はプリンター送信と造形を行わない。 | 未実施 |
| T-07 | 実造形・冷却・取外し時間 | 別途造形が許可された場合に記録する。印刷実時間45分以内、冷却と取外し15分以内、造形開始から取外し完了まで60分以内を目標とする。時刻を記録し、ユーザー報告の約30分というサンプル造形を実績比較に使わない。 | 試作品なし |
| T-08 | 造形後の形状と表面 | 全周・底面・窓Pocket・タイヤPocketを撮影し、割れ、層間剥離、欠け、鋭い欠陥、反り、形状欠損を記録する。欠陥が見つかった試作品は合格扱いせず、CADまたは工程へ戻す。この確認は外観・工程の評価で、安全性の証明ではない。 | 試作品なし |
| T-09 | 材料と試作品の追跡性 | PLA Basicの製品番号、色、ロット、現物ラベル、試作品ID、使用設定を対応づける。ラベルやロットが確認できなければ材料評価を保留する。 | 材料記録なし |
| T-10 | 子ども使用・安全性・規格適合 | 本計画では評価しない。子どもへの引き渡し、玩具としての使用、安全性または規格適合の主張を承認しない。用途を変更する場合は対象年齢と使用状況を定めて別の試験計画を作る。 | 保留 |

## 記録方法

各段階で、対象ファイルの版とSHA-256、使用材料と設定、実施日、個体ID、測定値、写真、観察結果、判定者、未解決事項を対応づける。各DRのbefore/after原本とmanifestは親担当が `reviews/DRx/` に保存する。本書の改訂も旧版を上書きせず、`revisions/` に保管する。

## 合否の扱い

R-02の寸法目標には許容差がない。測定値と目標との差を記録し、寸法の安全合格とは扱わない。R-09の時間目標はスライサー予測と実測を分ける。DR3の造形後確認に合格しても、機械的強度、材料の化学特性、長期耐久性、子ども使用の安全性、規格適合を確認したことにはならない。
