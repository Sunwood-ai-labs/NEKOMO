# 床なし・中空・2色ミニバス v07

FreeCADで作成した40 mm級の一体バス。床と座席はなく、内部は底側へ開放している。窓は貫通、タイヤは外縁のテーパーとハブ溝がある固定輪。正立時は上部白、下部赤の2色で、印刷時は屋根を下にする。

## 実データの確認結果

| 項目 | 結果 |
| --- | --- |
| CAD外形 | 40 × 20 × 22.05 mm。公称高さ22 mmに対し、輪の重なり用形状で0.05 mm増加 |
| 形状 | 再読込後も有効な閉じた1ソリッド。材料部分は一体で、内部空間と床側開口がある |
| 選定箇所の厚さ | 側壁・屋根中央・前壁・前窓中央柱は各1.6 mm、側窓間の柱は2.1 mm。全域の最小肉厚や強度を確認した値ではない |
| 色境界 | 正立Z10 mm、印刷Z12 mm。共有面175.36 mm²、色領域の重複・欠損・余剰は0 mm³ |
| スライス | 0.20 mm、3壁、15% gyroid、110層、支持材なし、色替え1回、警告なし |
| 予測時間 | タワー・色替え・初期動作を含む1プレート全体で1,721.266秒、約28分41秒 |
| 材料予測 | モデル本体5.188 g、パージとプライムを含む合計6.991 g |
| 60分目標 | 冷却と取り外し15分の計画予算を加えると約43分41秒。実時間は未測定 |

最初のスライスは範囲外経路で停止した。バスの配置を保持し、色替え用タワーをX20/Y20へ明示した新しいプロジェクトとプロファイルで再スライスし、正常終了した。元データは上書きしていない。

最終G-codeの解析では、白のモデル押出はZ0.2〜12.0 mm、赤はZ12.2〜22.0 mmだった。支持材タグはなく、屋根を越えた高さで空洞中央を塞ぐモデル経路もなかった。窓と輪の表面品質、層間と色境界の強度、実際の所要時間は未確認。

プリンターへは送信していない。DR0〜DR2はデータ上の審査を行い、DR3の現物試験は未実施、DR4の使用開始判定は保留。旧v06以前の設計は保存している。
