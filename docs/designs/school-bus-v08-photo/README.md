# 参照画像のスクールバス形状試作 v08

画像の丸い輪郭、貫通窓、空洞、床の開放、固定タイヤをFreeCADで試作した。元の議論にあった赤白2色を使い、旧版と進行中のv07は編集していない。ライト、グリル、飾り帯などの細部は今回の形状試作では省いた。参照画像の完全再現版ではない。

## 保存した成果物

- `cad/photo-bus.FCStd`: 赤い車体、白い屋根と固定タイヤ。
- `cad/photo-bus-fast.FCStd`: 同じ形状で赤い車体とタイヤ、白い屋根。
- `cad/photo-bus-print-orientation.FCStd`: 屋根を下にした造形方向。
- `exports/*-two-color-sliced.3mf`: それぞれの保存済みスライス結果。プリンターには送信していない。
- `evidence/`: 参照画像、FreeCAD画像、形状検査、失敗を含むスライス結果、保存した3MFの検査記録。

## 確認結果

全長42 × 幅21 × 高さ24 mm。壁厚は基本1.6 mmで、丸めや窓周囲の局所厚さは別途現物評価が必要。車体とタイヤを合わせた形状は有効で閉じた1ソリッド。床の中央に置いた検査領域と形状の交差体積は0。色領域間の重複は0で、合成後と元形状の体積差は約0.0000013 mm³。屋根の平らな接地面は約364.56 mm²。FCStdを保存して開き直し、1ソリッドを再確認した。

| 配色 | 予測時間 | 色替え | 総材料 |
| --- | ---: | ---: | ---: |
| 赤い車体、白い屋根とタイヤ | 89分10秒 | 28回 | 20.54 g |
| 赤い車体とタイヤ、白い屋根 | 約29分54秒 | 1回 | 5.82 g |

条件はBambu Studio、A1 mini 0.4 mm、PLA Basic、0.20 mm層、3壁、15%充填、支持材なし、プライムタワーあり、各1台。予測はスライサーの総時間であり、冷却と取り外しは含めない。実際の材料装填状態や実機ノズルは今回確認していない。赤白は元スレッドの希望を引き継いだ。黄色と茶色の実スライス結果ではない。

## スライス後の判断

1時間目標では、タイヤを車体と同色にする案を推奨する。屋根とタイヤを同じ白にすると、タイヤのある層で赤と白の往復が必要になり、色替えが28回になった。材料差にはパージとタワー等が含まれるため、差の全量をパージ量とは扱わない。

両案ともスライサーの終了コードは0、warning_messageは空。保存した3MFもファイル単位で再検査し、A1 mini、0.4 mm、2色PLA、119層を確認した。この結果で窓下の短いブリッジ、屋根の丸みを下にした初層付近の広がり、タイヤの張り出しの現物品質までは確認できない。窓の主な幅は6.4 mm。屋根の平面を確保したが、丸み部分の積層と接地の安定性は初回試作で確認する。形状試作の採用候補であり、印刷・強度・幼児向け使用の合格判定ではない。全DRの再実施は今回行っていない。

最初の2色スライスはタワーの領域外エラーで失敗した。`profile.json`と失敗記録を残し、タワー座標をX15/Y130へ変更した`profile-tower-fixed.json`で再スライスした。旧版の予測時間は流用していない。

## 適用した原則

Prove It Worksに従い、CADの再読込と、保存した最終3MFの直接検査で確認した。Model the Domainに従い、主要寸法を設計パラメーターとして保存した。Prototypeの手順でv08を独立した試作にし、画像寄りの配色と1時間目標の配色を同じ形で比較した。
