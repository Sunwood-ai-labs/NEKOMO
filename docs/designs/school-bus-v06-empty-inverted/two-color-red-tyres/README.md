# 赤いタイヤの別バージョン

屋根と4輪のタイヤを赤、車体とタイヤ中央のハブを白にしました。使う色は赤白の2色です。従来の白タイヤ版を残し、色分けだけを変更した別のFreeCADモデルと印刷データを保存しました。

床と座席を除いた形、大きさ約60×34×35.6 mm、固定輪は同じです。CAD上の色領域の交差・欠落・余剰は0 mm³です。赤の5領域は屋根と4輪、白の5領域は車体と4つのハブであり、別々の脱着部品を追加したわけではありません。

| バージョン | 印刷時間の予測 | 総材料 | 色替え |
|---|---:|---:|---:|
| 白いタイヤ | 1時間14分42秒 | 24.17 g | 1回 |
| 赤いタイヤ・白いハブ | 2時間35分38秒 | 43.46 g | 40回 |

両方とも上下逆、通常型PLAサポート、0.4 mmノズル、層高0.25 mm、外壁2周、内部10%の条件です。どちらもスライサー警告はありません。各条件1回のスライサー予測で、実際の印刷時間ではありません。総材料にはサポート、排出、吐出を整える塔を含みます。

赤いタイヤ版では、タイヤを造形する高さで赤いタイヤと白い車体・ハブを切り替えるため、色替えが増えます。実G-codeの交換記録も40回でした。色分けの体積だけを基に時間を推定せず、実スライスを比較しました（Prove It Works）。

`nekomo-v06-red-tyres.FCStd`が別バージョンのネイティブCAD、`red-tyres-inverted-sliced.3mf`が上下逆のスライスです。`geometry.json`、`mesh-check.json`、`slice-result.json`、`file-inspection.json`、`comparison.json`に検証を記録しました。

2026-11-10 05:22 JSTに、ユーザーの指示で赤タイヤ版の実機印刷を開始しました。A1 miniで赤PLAをA3、白PLAをA1に割り当てています。記録は`print-run-20261110/`に保存しています。完成品、支持材の除去、強度、子どもの使用安全性はまだ未検証です。
