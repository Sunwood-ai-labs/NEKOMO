# ネコネコインダストリーの採用ロゴと機体への刻印

採用済み素材を再発見し直さず使い、公式画像と刻印用の派生形状を区別する。プロジェクトルートは、このスキルフォルダから3階層上。以下のパスはルート基準。

## 正式な素材と表記

最初に `docs/brand/identity.md` と対象機体のREADMEを読む。正式な採用状況はその時点の記録で確認する。

- 採用ロゴは38「ねこ船長」。原本は `docs/brand/logo.png`。元案は `docs/brand/logo-concepts/38-cat-captain.png`。
- 会社名は「ネコネコインダストリー / NEKONEKO INDUSTRIES」。NEKOMOは過去資料に残る旧表記で、現行ブランドとして使いません。機体名とは区別する。
- `NNI-TR`は新しいトラブル記録に使う接頭辞です。文字だけのNNIを採用ロゴと扱わず、「ロゴを入れた」と報告しない。
- 資料へ採用ロゴを置くだけなら原本を使う。刻印用の輪郭、簡略化、文字や標語の省略は用途別の派生物として保存し、原本を上書きしない。新ロゴ案の依頼がなければロゴを作り直さない。

## 刻印の設計

1. 対象のCAD版、造形姿勢、表面と裏面、読める向きを確認する。短い機体名とシンボルを優先し、長い社名全文を狭い面へ無理に置かない。
2. 底面を提案する場合は、車軸、可動隙間、床厚、接地面を避けられるかを見る。底面指定はLYNXの今回の選択であり、別機体へ一律には強制しない。
3. 幅、高さ、彫り込み深さ、最小線幅・隙間、残る肉厚を記録する。ノズル径、積層、材料、造形方向に合わせて決め、固定値を造形保証にしない。
4. 派生輪郭は対象リビジョンのsourceへ保存し、原本パス・SHA-256、切り出し範囲、簡略化条件を残す。FreeCADでは面・穴を保持し、実際にボディを切削する。表示だけの文字と実形状を区別する。

LYNX r05は再利用の例として `designs/nkm-c01-lynx/r05/` にある。底面のシンボル幅14 mm、LYNX文字列幅約20.445 mm、彫り込み0.6 mm。屋根のNNI＋LYNX案はr04に不採用案として残す。これらの寸法は他の機体の既定値にしない。

必要な実装だけ参照する。次の4ファイルはすべて `designs/nkm-c01-lynx/r05/source/` 内にある：`vectorize_logo.py`、`cat-captain-outline.json`、`build_lynx.py`、`params.json`。FreeCADの `Part.makeWireString` でWindowsフォントを指定するときはフォントディレクトリ末尾の区切りを含める。文字の閉じた輪郭と穴、裏面からの鏡像化を確認する。

## 確認と保存

形状変更は `docs/design-change-records.md` に従って新しいリビジョンへ保存する。隣の `nekoneko-development-codename/SKILL.md` を併用する。

- 刻印後の有効ソリッド、干渉、可動隙間、残る肉厚を確認し、裏から読める画像を保存する。
- 保存CADと書き出しを再読込する。深さの確認には断面や切削体積との照合など、実形状を使う。
- 印刷用データを作る依頼では、FDM設計・スライスガイダンスと既存の製作前確認規則を適用する。刻印部の経路が省略・充填されていないかも確認し、未確認なら明記する。
- CAD上で見えること、スライスに残ること、実物で読めることを別々に報告する。ロゴ刻印の追加だけを理由に印刷や外部公開を始めない。
